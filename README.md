# Tug of Word

A multiplayer word-guessing game where two players take turns pulling the rope — one letter at a time.

## How to play

1. Player 1 thinks of a secret word and enters it.
2. Player 2 guesses letters one at a time.
3. Each correct guess pulls the rope toward Player 2; each wrong guess pulls it toward Player 1.
4. The player whose side the rope reaches first wins!
